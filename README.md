# 🍗 Red Bucket Biryani – Jodimetla Branch, Hyderabad

> **Official Website for Red Bucket Biryani – Jodimetla Branch.**  
> Crafted with a premium restaurant dining experience, authentic bucket biryani showcase, real customer storytelling, interactive menu, and instant WhatsApp & phone ordering.

---

## 🌟 Overview

Red Bucket Biryani (Jodimetla Branch) is renowned for serving authentic dum-cooked Hyderabadi biryani in signature food-grade takeaway buckets that lock in aroma, steam, and flavor. This modern web application provides a responsive, mobile-first digital storefront for browsing bucket sizes, checking transparent pricing, exploring customer moments, and placing instant takeaway or dine-in orders.

---

## ✨ Key Features

- **🏆 Brand Hero Showcase**: High-impact visual presentation showcasing the signature Red Bucket Biryani bucket with warm atmospheric lighting and quick direct order CTAs.
- **🍗 The Iconic Bucket Biryani Experience**: Real customer experience showcase highlighting takeaway and dine-in gatherings.
- **🪣 Choose Your Bucket (5 Distinct Experiences)**:
  - **Solo Bucket** (1–2 Pax, 2 Eggs, 2 Chicken Pieces)
  - **Connecting Bucket / Duo** (2–3 Pax, 2 Eggs, 3 Chicken Pieces)
  - **Family Bucket** (3–4 Pax, 3 Eggs, 4 Chicken Pieces)
  - **Jumbo Bucket** (5–6 Pax, 4 Eggs, 6 Chicken Pieces)
  - **Party Bucket** (7–8 Pax, 5 Eggs, 8 Chicken Pieces)
- **👑 Mega Feasts & Special Packs**:
  - **Special All Mix Bucket** (Chicken Dum, 65, Lollipop, Wings & Prawns)
  - **The Mighty Sixty (60 Pax)** (60 boiled eggs, 60 tender chicken pieces, salan & raita)
- **📋 Complete Interactive Menu**: Filterable menu with accurate branch pricing across Chicken Dum, Special Chicken, Mutton Dum, Prawns, Fish, Egg, and Veg Biryani varieties, plus Starters and Extras.
- **⭐ Google Reviews & Testimonials**: Genuine customer reviews and invitation to share dining feedback.
- **📍 Branch Location & Hours**: Integrated Google Maps directions, address, and live operating hours (12:00 PM – 1:00 AM every day).
- **📱 Instant Contact & Ordering**: Sticky WhatsApp and direct phone calling buttons (`8008906029`).
- **⚡ Mobile-First & Ultra Fast**: Fully responsive layout tailored for mobile devices, tablets, and desktops.

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (v18 or higher recommended) and `npm` installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/JoelAstro/Red_Bucket_Biryani_jodimetla.git
   cd Red_Bucket_Biryani_jodimetla
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview the production build:**
   ```bash
   npm run preview
   ```
   Open [http://localhost:4173](http://localhost:4173) in your browser.
